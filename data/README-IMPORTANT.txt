This folder will automatically store every Contact Us form submission
in a file called "contact-submissions.csv" once your first enquiry
comes in through the website.

HOW TO VIEW YOUR ENQUIRIES:
1. Log in to your hosting File Manager (or connect via FTP).
2. Open the "data" folder inside your website.
3. Download "contact-submissions.csv" and open it in Excel or Google Sheets.

This file is blocked from public/browser access for privacy (see .htaccess),
so only you (via File Manager/FTP) can read it.
