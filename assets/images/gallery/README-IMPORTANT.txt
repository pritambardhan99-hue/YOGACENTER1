GALLERY PHOTOS — FULLY AUTOMATIC
==================================
Just drop your photo files directly into this folder. That's it.

- No code editing needed — the Gallery page scans this folder automatically
  every time someone visits it.
- ANY common format works: JPG, JPEG, PNG, WEBP, GIF, AVIF, SVG.
- ANY size or resolution works — big phone photos, small screenshots,
  wide or tall pictures — each one is automatically cropped/fitted into a
  clean, uniform card so the gallery always looks tidy, no matter what you
  upload.
- The photo title shown on the site is generated automatically from the
  filename (e.g. "morning-yoga-session.jpg" becomes "Morning Yoga Session").
  For a nicer custom caption or a specific category (yoga / meditation /
  ayurveda / retreat), you can optionally add a line inside the
  $gallery_overrides array near the top of gallery.php — but this is
  optional, not required.
- To remove a photo from the site, simply delete it from this folder.

Recommended (not required): keep individual photos under ~3MB for the
fastest page loading.
